# Worker app: screen to API traceability (PRD 6.1 - 6.4)

One row per atomic field, action or workflow step of the Worker application requirements. The Flutter application is not in this repository: every row proves the BACKEND contract only; the screen-to-network integration is NOT_VERIFIED.

Evidence rules: a row is PASS_VERIFIED only when the behaviour is exercised by an automated integration test on a disposable local database (names below are the exact test titles, resolved from the spec files) and the latest full run passed. Real providers, mobile screens and the deployed environment are recorded separately. Run result: integration run of 2026-10-13: see docs/qa/phase-verification-results.md.
