# Favourites and Interviews: notes for the customer-app team

Backend definitions only; the app repository was not available. Everything below is additive, nothing is removed or renamed.

| Request              | Answer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 `monthlyRate`      | **Not available.** Worker pay is private to customers and has no period or range. Keep omitting the price until the client decides (Q-137a).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 2 Duration           | Use `durationMinutes` (60) on every interview. End = `scheduledAt` + `durationMinutes`. `slotMinutes` on `/slots` is always present and has the same value.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 3 Worker on the list | Use `worker.{workerId,name,initials,photoUrl}` of `GET /interviews`; remove the booking and worker-detail calls.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 4 Timeline           | Done and failed steps always have `at`; pending ones have `null`. Do not template when `timeline` is empty: it always has at least "Requested". Rescheduling history is not kept (Q-137c).                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 5 Counts             | Use `counts.{upcoming,past,total}` for the tabs. They cover all interviews, not the current filter; use `meta.total` for the filtered size.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 6 Next interview     | `GET /interviews?scope=upcoming&limit=1`, or `upcomingInterview` on Home (confirmed only).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 7 Favourites chips   | Use `categoryCounts[]` (`code`, `name`, `count`) and `GET /shortlist?category=CODE`. "All" is the unfiltered `meta.total`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 8 Reason code        | **Added on the card:** `canRequestInterview` (true) and `cannotRequestReason` (null). `VERIFICATION_PENDING` is reserved and cannot occur on a card today, because only verified workers have a card; an unavailable shortlist entry has `worker: null`, `available: false` and no reason. Earlier note: **Not available.** Every card in the shortlist or search is a verified, active worker; if a card is shown, interview eligibility of the worker is not the blocker. The request itself is refused with an error when it is not allowed (for example 409 INVALID_INTERVIEW_STATE or INTERVIEW_ALREADY_OPEN). Waiting on Q-137e. |

Paging has no `totalPages` or `hasNextPage`: next page exists while `page * limit < meta.total`.
